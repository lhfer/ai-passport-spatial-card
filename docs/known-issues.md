# 已知问题

公开版本基于 B5 原型整理。这一轮验证关注公开包的完整性、匿名资源、构建和模拟演示。

- **跟踪角度与遮挡。** 平放时的斜视、背面朝向和手部遮挡会降低识别。暂时跟丢时，名片保留上次位置，重新识别后可能滑向设备。
- **跟丢时变暗。** 默认保持提示可能降低名片可读性；另有尚待定位的透明度变化。
- **过场性能。** 作品卡片的粒子拖尾仍可能降低帧率，尤其是扇出和放下过程。不要用模拟器帧率推断头显表现。
- **性能调试开关。** `cmd perf gallery=off` 后 `reset` 可能让画廊交互停留在收起状态，需重新启动 App。普通演示不要使用这一调试组合。
- **匿名主题与模型。** 模型权重不变，但屏幕改成了匿名素材；在用户自己的设备上需要重新确认识别表现。
- **本地 Hub。** 真实设备模式没有认证机制，仅供可信局域网；网页数据源可能出现登录墙或布局变化。

公开动图来自模拟器运行；实际设备透视、空间遮挡、按键链路和跟踪稳定性需要真机验收。
